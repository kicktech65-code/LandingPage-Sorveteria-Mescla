# LandingPageSorveteria
# 🍦 Mescla — Landing Page

Landing page moderna e responsiva desenvolvida para a **Mescla**, uma sorveteria e lanchonete especializada em oferecer opções para todos os gostos, desde sobremesas e sorvetes até hambúrgueres e pizzas.

O projeto foi desenvolvido com foco em **experiência do usuário, apresentação visual dos produtos e conversão**, utilizando uma interface limpa, moderna e adaptada para dispositivos móveis.

## ✨ Funcionalidades

* 📱 Layout totalmente responsivo
* 🍦 Apresentação de sorvetes, açaís e milk-shakes
* 🍔 Seção de hambúrgueres
* 🍕 Seção de pizzas e bebidas
* ⭐ Depoimentos de clientes
* 🛒 Chamadas para ação direcionadas para pedidos
* 📋 Apresentação visual do cardápio
* 📲 Menu responsivo para dispositivos móveis
* ✨ Animações e efeitos de interação
* 🔍 SEO básico com meta tags
* 🌐 Open Graph para compartilhamento em redes sociais
* 📍 Informações comerciais estruturadas com Schema.org

## 🛠️ Tecnologias utilizadas

* **HTML5**
* **Tailwind CSS**
* **JavaScript**
* **Google Fonts — Poppins**
* **SVG Icons**
* **Schema.org / JSON-LD**

## 🎨 Design

A identidade visual utiliza uma combinação de tons **marrom, laranja e branco**, criando uma estética acolhedora e relacionada ao universo de sobremesas e alimentação.

As imagens dos produtos, efeitos de hover, animações de entrada e elementos de destaque foram utilizados para tornar a navegação mais atrativa e estimular o usuário a conhecer o cardápio e realizar um pedido.

## 🚀 Como executar

Como o projeto utiliza HTML, Tailwind CSS via CDN e JavaScript, não é necessário instalar dependências.

Basta clonar o repositório e abrir o arquivo `index.html` no navegador:

```bash
git clone <url-do-repositorio>
cd LandingPageSorveteria
```

Depois, abra o `index.html` no navegador.

## 🎯 Objetivo do projeto

O objetivo foi criar uma landing page que não apenas apresentasse os produtos, mas conduzisse o visitante por uma jornada simples:

**Conhecer → Explorar o cardápio → Escolher → Fazer o pedido.**

O projeto também demonstra a aplicação prática de conceitos de **UI/UX, responsividade, hierarquia visual, acessibilidade, SEO e desenvolvimento front-end**.
